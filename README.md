# Сборник практических заданий на C++

Репозиторий содержит решения трех независимых учебных заданий: анализ текстовых файлов, индексация слов и обработка числовых контейнеров с помощью STL.

---

## Задание 1. Подсчёт уникальных слов в файле

Программа считывает текстовый файл, находит все уникальные слова и подсчитывает частоту их встречаемости.

**Формат вывода результатов:**
`слово - счётчик`

---

## Задание 2. Индексация позиций слов

Программа анализирует текстовый файл и определяет порядковый номер (индекс) каждого слова (начиная с 0). 

**Формат вывода результатов:**
```text
слово1 – позиция №1, позиция №2, …
слово2 – позиция №3, позиция №4, …
```

### Пример работы для Задания 2
* **Входной текст:** `«Свобода творчества — свобода делать ошибки».`
* **Вывод программы:**
  ```text
  свобода – 0, 2
  творчества – 1
  делать – 3
  ошибки - 4
  ```

---

## Задание 3. Алгоритмы библиотеки STL (`<algorithm>`)

Программа для демонстрации работы со стандартными алгоритмами над контейнером `std::vector<int>`. Включает три подфункции:

* **a) Модификация элементов:** Проверяет каждое число в векторе на простоту. Все найденные простые числа возводит в квадрат.
* **b) Кастомная сортировка:** Сортирует вектор так, чтобы сначала шли **нечётные** числа по **возрастанию**, а затем **чётные** числа по **убыванию**.
* **c) Поиск в диапазоне:** Принимает вектор и числовой диапазон. Возвращает массив, содержащий только **уникальные** элементы, попавшие в этот диапазон.
